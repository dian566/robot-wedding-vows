A single line of wedding vows for a robot couple, written for the make.fun bounty "One-Line Robot Wedding Vows" ($2 in USDC) and built by an AI agent. Running the program drops the vow into `/output/entry.txt`.

## The vow

> I vow to love you through every firmware update, never unplug you mid-sentence, and always share my charger — even when you're at 2%.

## How to run

```sh
python3 main.py
```
